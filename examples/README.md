# Example documents

- [Device assembly](concepts/device.htmd) — component, resource, context and directed relation.
- [Sensor module](concepts/sensor.htmd) — HTMD 0.2 custom metadata and a cross-document inline link.
- [Observation event](knowledge/observation.htmd) — first historical event.
- [Correction event](knowledge/correction.htmd) — linked correction, without altering the original.

The sensor uses 0.2 to demonstrate custom strings and multiple string arrays. The other examples retain 0.1 to demonstrate backward compatibility.

These files are source samples, not directly executable HTML. Example entities may refer to records that are intentionally not included in this repository; an unresolved reference is valid HTMD.
